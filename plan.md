# Atlas Coalition reference UI

## Implementation

Adapt the existing static site to the supplied mobile screenshots without changing its data model or routes. Preserve the existing accessible header, menu, content sections, member data and SVG policy visual; refine the responsive CSS so the mobile experience uses the screenshot's editorial navy/cream palette, compact square brand mark, large serif hero, stacked policy atlas card, two-column metric band, spacious about section, and bordered mission cards. Desktop layout remains the existing multi-column system with the same brand language.

## Design

- **Design movement:** institutional editorial / policy journal.
- **Core principles:** high-contrast reading hierarchy, calm evidence-led spacing, responsive card rhythm, and restrained teal accents.
- **Color philosophy:** deep navy signals trust and governance; warm paper keeps the institution human; teal marks action and verified data.
- **Typography system:** Newsreader/Georgia for editorial headings; system sans for UI; monospace eyebrow labels for registry language.
- **Signature elements:** square A seal, policy-atlas network card, teal hairlines and metric numerals.
- **Interaction:** mobile navigation becomes a full-width readable panel; buttons stay large and touch-safe; cards retain clear borders and links.
